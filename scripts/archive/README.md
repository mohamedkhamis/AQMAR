# scripts/archive/

Exploratory / proof-of-concept scripts kept for reference only. They are **not**
part of any live pipeline, are not maintained, and may reference an older
architecture (pre-SQL-Server). Do not run them without reviewing the code first.

- `phase0_sample.py` — early phase-0 sampling experiment.
- `investigate_photos.py` — one-shot photo-investigation script.
- `investigate_speed.py` — one-shot download-speed investigation.
- `test_partial_video.py` — partial-video-download PoC (despite the `test_` name,
  not a pytest test — `pytest.ini` scopes collection to `tests/`).
